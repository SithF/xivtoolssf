FFLogs API 配置

请在 FFLogs 官网申请个人 API 凭证（免费、步骤简单）： 1. 登录 https://cn.fflogs.com 2. 进入「我的账号」→「API 客户端」创建客户端 3. 将生成的 Client ID 与 Client Secret 填入下方并保存 凭证仅保存在你当前浏览器的 localStorage 中，用于向 FFLogs 获取访问令牌，不会上传至本工具之外的任何服务器。

使用说明

📖 图文教程：如何申请 FFLogs API → 📖 图文教程：工具使用说明 →

1. 点击「FFLogs API 配置」，按提示申请并填写 Client ID / Client Secret（一次性，保存在本机浏览器）。 2. 打开 FFLogs 战报页面，复制浏览器地址栏链接，链接需包含具体战斗编号，例如： https://cn.fflogs.com/reports/AbCdEfGh?fight=3 也可以用 ?fight=last 表示最后一场战斗。 3. 粘贴链接后点击「1. 解析日志」，等待加载完成。 4. 在「受伤统计对象」和「施法统计对象」中分别勾选需要统计的角色，点击「2. 确认筛选玩家」。 5. 在「技能筛选」中勾选需要展示在时间轴上的技能（蓝色高亮为常用技能，已默认勾选），点击「3. 筛选所选技能」。 6. 点击底部按钮导出 CSV 表格或 HTML 时间轴。 所有数据处理均在你的浏览器本地完成，不会上传到本工具之外的任何服务器。
